# skylenta-ab-test
# Дипломная работа: Анализ эффективности маркетинговых коммуникаций для ритейлера SkyLenta

## 📌 Описание проекта
В данном проекте проведен комплексный статистический анализ результатов A/B-тестирования новой механики коммуникации с клиентами. Цель исследования — определить эффективность замены классических баннеров в приложении на таргетированные пуш-уведомления.

## 📊 Исходные данные
Для анализа использовался массив данных из трех связанных таблиц (`Данные`, `Clients`, `Region_dict`), включающий информацию по 55 356 клиентам и их транзакциям. 

В ходе предобработки данных:
* Удалены пропуски и некорректные записи.
* Исключены торговые точки с нулевой выручкой или отсутствием участников в тестовой/контрольной группах (всего отфильтровано 15 аномальных ID точек).
* Итоговый объем очищенных данных для анализа составил **45 318 записей**.

## 🚀 Ключевые результаты эксперимента

### 1. Общие метрики по всей сети:
* **Конверсия в платёж:** В контрольной группе (баннеры) составила **49.98%**, в тестовой (пуш-уведомления) — **54.33%**. Прирост составил **+4.35 процентных пункта**. Разница статистически значима ($p\text{-value} = 0.0000$).
* **Чистый средний чек (среди платящих):** В контрольной группе — **4380.48 руб.**, в тестовой — **4513.81 руб.** Прирост составил **+133.32 руб.** Разница статистически значима ($p\text{-value} = 0.0002$).
* Общий сдвиг распределения бюджетов покупателей математически подтвержден непараметрическим критерием Манна-Уитни ($p\text{-value} = 0.0000$).

### 2. Результаты региональной сегментации:
* **Москва, Санкт-Петербург и Самара:** Продемонстрировали сильный и одновременный статистически значимый рост как конверсии, так и среднего чека.
* **Тюмень и Сочи:** Пуш-уведомления значимо увеличили только конверсию, не изменив средний чек.
* **Волгоград и Владимир:** Изменения зафиксированы только на уровне отдельных сегментов (по тесту Манна-Уитни), средние показатели значимо не изменились.
* **Остальные регионы (Красноярск, Казань, Мурманск и др.):** Статистически значимых различий между группами не обнаружено.

## 🎯 Бизнес-рекомендации
1. **Полноценное внедрение:** Рекомендуется масштабное раскатывание механики пуш-уведомлений на ключевые регионы: **Москва, Санкт-Петербург и Самара**.
2. **Гибридный подход:** Для городов с точечным эффектом (Тюмень, Сочи, Волгоград, Владимир) целесообразно использовать дополнительную сегментацию аудитории или кастомные пуш-кампании.
3. **Заморозка изменений:** В остальных регионах экономически обосновано временно сохранить классические баннеры, так как пуш-сообщения там не продемонстрировали превосходства.
